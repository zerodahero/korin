Roll the api to a new image
params: image (required)

▸ Stage 1/2 · Current state  [read-only, no gate; valid --from start]
  1.1  read ❯ kubectl get deployment api -n shop -o json
        → current
  1.2  note "api runs <current ← 1.1>."

▸ Stage 2/2 · Roll  [mutating, gate; valid --from start]
  2.1  mutate ❯ kubectl set image deployment/api api=<image> -n shop
  2.2  read ❯ kubectl rollout status deployment/api -n shop --timeout 5m
