Run a wizard. Each stage is shown, and approved at its gate, before it runs

Usage: korin run [OPTIONS] <FILE>

Arguments:
  <FILE>  The wizard file

Options:
      --color <COLOR>            When to use color: `auto` colors a terminal unless `NO_COLOR` is set. Also set by the config key `color`; the default is `auto` [possible values: auto, always, never]
      --param <NAME=VALUE>       A value for a param or an `ask`, as `name=value`. Repeatable
      --yes                      Approve every gate. Allowed only without a terminal, for wizards that declare `unattended allowed`
      --from <FROM>              Start at this stage (title or number). Earlier stages count as done in an earlier run; a later stage that reads their values asks for them
      --skip <STAGE>             Skip this stage (title or number), and the stages that need its values. Repeatable
      --skip-preflight           Skip the preflight
      --set <NAME=VALUE>         A value for a capture or expect of a skipped stage, as `name=value`. Repeatable
      --kill-grace <KILL_GRACE>  Seconds between SIGTERM and SIGKILL when korin ends a command (at most 3600) [default: 10]
      --require-enter            Answer gates and `confirm` with y or n and then Enter, instead of a single key. Also set by `KORIN_REQUIRE_ENTER=1` or the config key `require-enter`
  -h, --help                     Print help
