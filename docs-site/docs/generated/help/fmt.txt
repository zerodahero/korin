Arguments:
  [FILES]...  Wizard and module files to format

Options:
      --check          Report files that are not formatted, without changing them
      --color <COLOR>  When to use color: `auto` colors a terminal unless `NO_COLOR` is set [default: auto] [possible values: auto, always, never]
  -h, --help           Print help
