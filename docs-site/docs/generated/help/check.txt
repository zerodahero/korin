Parse and check a wizard without running anything

Usage: korin check [OPTIONS] <FILE>

Arguments:
  <FILE>  The wizard file

Options:
      --color <COLOR>    When to use color: `auto` colors a terminal unless `NO_COLOR` is set. Also set by the config key `color`; the default is `auto` [possible values: auto, always, never]
      --format <FORMAT>  Output format for diagnostics [default: human] [possible values: human, json]
      --from <FROM>      Also list what a run that starts at this stage (title or number) asks for
  -h, --help             Print help
